# Antigone · A Companion

An interactive companion to Sophocles' *Antigone* — a quiet, offline reader's guide to the
play's characters, themes, scene-by-scene structure, and the ideas it set loose. It is a
companion to the tragedy, **not the text of the play itself**.

Everything lives in a single self-contained `index.html`: all styles and behavior are
inline, with no build step, no dependencies, and no network access. It works just as well
opened from your desktop as served from the web.

## View it live

**https://bip-river.github.io/antigone/**

Published automatically from `main` via GitHub Pages (see
[`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml)).

## Use it offline

Download [`index.html`](index.html) and open it in any browser. That's the whole app — no
internet connection required.

## What's inside

- **Characters** — Antigone, Creon, Haemon, Ismene, Tiresias and the rest, each with an
  essence, layered sections, and cross-links.
- **Themes** — law and defiance, family and the dead, power and the city, the doomed house.
- **By the play** — a scene-by-scene spine following Sophocles' structure, from the
  pre-dawn prologue to the exodos.
- **Reference** — a cross-linked glossary of people, places, ideas, and objects, with
  hover-to-peek previews.
